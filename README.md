# Цифровой ППР

Веб-приложение для автоматизации планово-предупредительных работ (ППР) в подразделениях Трансэнерго (ОАО «РЖД»).

## Зачем это нужно

Раньше каждое подразделение вело годовые и месячные планы вручную — на бумаге и в Excel. Инженер тех. отдела параллельно дублировал те же данные у себя для проверки. Рапорты о невыполненных работах писались от руки. Суммарно по дистанции — около 912 человеко-часов в год только на эту работу.

Система централизованно хранит планы, автоматически строит месячные планы из годового, формирует рапорты и сводные отчёты по всей структуре — от цеха до Трансэнерго.

## Что умеет система

- **Годовой план** — нормы времени встроены, можно добавить ненормированные работы вручную
- **Месячный план** — строится автоматически из годового, готов к печати
- **Переносы работ** — выбрать объём и месяц, годовой план обновится сам
- **Согласование и утверждение** — роли пользователей и процесс согласования соответствуют нормативным документам
- **Сводные отчёты** — по цехам, дистанциям, дирекциям и Трансэнерго в целом (по работам и трудозатратам)

## Участники процесса

| Роль                       | Что делает в системе                              |
| -------------------------- | ------------------------------------------------- |
| Начальник цеха             | Ведёт план, вносит выполнение, оформляет переносы |
| Инженера                   | Проверяют планы, смотрят сводные данные           |
| Руководство дистанции / ТЭ | Согласует, утверждает, просматривает аналитику    |

## Технологии

Next.js 14 (App Router) · React 18 · TypeScript · Ant Design · Drizzle ORM + MySQL · NextAuth

## Запуск

**Требования:** Node.js 18+, MySQL

1. Установить зависимости:

   ```bash
   npm install
   ```

2. Создать `.env.local` на основе примера:

   ```env
   DB_HOST=localhost
   DB_PORT=3306
   DB_NAME=ppr
   DB_USER=root
   DB_PASSWORD=secret
   NEXTAUTH_SECRET=your_secret
   NEXTAUTH_URL=http://localhost:3000
   ```

3. Запросить БД у разработчика. Применить миграции БД:

   ```bash
   npm run db:migrate
   ```

4. Запустить:
   ```bash
   npm run dev        # разработка
   npm run build && npm run start  # продакшн
   ```

## Структура проекта

Проект следует методологии [Feature-Sliced Design](https://feature-sliced.design/):

```
src/
├── 1shared/     # Общие UI-компоненты, утилиты, хелперы
├── 2entities/   # Бизнес-сущности (ppr, user, division...) — здесь же схемы БД (Drizzle)
├── 3features/   # Пользовательские действия: создание, обновление, перенос работ, экспорт
├── 4widgets/    # Составные блоки: таблица ППР, отчёты, лейауты
├── 5pages/      # Компоненты страниц
└── app/         # Next.js App Router — маршруты и Server Actions
```
